# Football — مشروع Android Studio

تطبيق أندرويد بسيط بواجهة عصرية يعرض ثلاثة روابط. عند اختيار رابط يمكن فتحه داخل التطبيق عبر WebView أو خارجه في المتصفح/التطبيق المناسب.

## المتطلبات
- Android Studio حديث
- JDK 17 (يُدار غالباً تلقائياً من Android Studio)
- اتصال بالإنترنت عند مزامنة Gradle وعند تشغيل الروابط

## فتح المشروع
1. فك ضغط `FootballAndroidProject.zip`.
2. افتح Android Studio واختر **Open** ثم اختر مجلد `FootballAndroidProject`.
3. انتظر انتهاء Gradle Sync. إذا طلب Android Studio تثبيت Android SDK Platform 35، وافق.
4. لتجربة التطبيق، اضغط **Run** مع اختيار هاتف متصل أو محاكي.

## إنشاء ملف APK للتثبيت
1. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
2. عند اكتمال البناء، اضغط رابط **locate** في إشعار Android Studio.
3. عادةً يوجد APK التجريبي في:
   `app/build/outputs/apk/debug/app-debug.apk`
4. انقل الملف إلى هاتف Android وافتحه. قد تحتاج إلى السماح بتثبيت التطبيقات من هذا المصدر في إعدادات الهاتف.

لإنشاء نسخة إصدار موقعة للتوزيع:
**Build > Generate Signed Bundle / APK > APK**، ثم أنشئ مفتاح توقيع واحتفظ به بأمان.

## تخصيص الروابط
عدّل القائمة `links` في `MainActivity.kt`، ثم أعد بناء التطبيق.

## ملاحظات
- التطبيق لا يستضيف الفيديوهات؛ إنه يفتح صفحات الويب التي تحددها فقط.
- قد تمنع بعض المواقع العرض داخل WebView أو تتطلب متصفحاً خارجياً أو تسجيل دخول.
- استخدم فقط المحتوى الذي تملك حق الوصول إليه، والتزم بشروط المواقع والقوانين المحلية.
- المشروع لا يتضمن ملف APK مبنياً مسبقاً؛ يجب بناؤه عبر Android Studio.
